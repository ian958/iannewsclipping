## 다이어그램 1: 전체 파이프라인 (역할 + 결정 주체)

```mermaid
flowchart TD
    A[사람: 전문가 워크샵\n결정: seed 키워드] --> B[사람: Claude에 확장 요청]
    B --> C[Subagent: 키워드 확장\n결정: 확장 개수 / 제외 추천]
    C --> D[사람: 검토 및 선택\n결정: 최종 키워드 확정]
    D --> E[사람: 빅카인즈 검색\n결정: 기간 / 언론사 범위\n결과: N건 수집]
    E --> F[사람: CSV 다운로드 + 전처리]
    F --> G[사람: Claude에 CSV 업로드]
    G --> H[Subagent: 클러스터링\n결정: 유사도 임계값\n결정: 클러스터 개수\n결정: 대표 기사 선정]
    H --> I[사람: 결과 검토 / 수동 조정\n출력: M건]
    I --> J[사람: 스코어링 프롬프트 입력]
    J --> K[Subagent: 스코어링\n결정: 각 뉴스 1-10점\n결정: 최적 필터링 임계점 제안\n결정: 예상 출력 건수 제시]
    K --> L[사람: 임계점 승인 / 조정\n출력: K건]
    L --> M[Subagent: 요약 / 분류\n결정: 요약 길이\n결정: 카테고리 분류 적용\n결정: 카테고리별 분포 보고]
    M --> N[사람: 최종 리포트 정리]

    style C fill:#e1f5ff,stroke:#0288d1
    style H fill:#e1f5ff,stroke:#0288d1
    style K fill:#e1f5ff,stroke:#0288d1
    style M fill:#e1f5ff,stroke:#0288d1
```

> **범례:** 파란 배경 = Subagent(Claude)가 자율 결정하는 단계

## 다이어그램 3: Before vs After 프로세스

```mermaid
flowchart LR

        B1[사람: 키워드 설계] --> B2[사람: 뉴스 검색]
        B2 --> B3[사람: 수동 중복 제거]
        B3 --> B4[사람: 관련성 판단]
        B4 --> B5[사람: 요약 작성]

    subgraph AFTER["After (Subagent 자동화)"]

        A3 --> A4[Subagent: 스코어링\n임계점 자율 제안]
        A4 --> A5[Subagent: 요약/분류\n자율 처리]
        A5 --> A6[리포트]
    end

    style A3 fill:#e1f5ff,stroke:#0288d1
    style A4 fill:#e1f5ff,stroke:#0288d1
    style A5 fill:#e1f5ff,stroke:#0288d1
```

## 다이어그램 4: Subagent 자율 결정 흐름

```mermaid
flowchart TD
    subgraph Human["사람 역할"]
        H1[데이터 업로드]
        H2[프롬프트 작성]
        H3[결과 검토]
        H4[최종 승인/조정]
    end

    subgraph Subagent["Subagent 자율 결정"]
        S1[데이터 분포 분석]
        S2[최적 파라미터 결정]
        S3[결과 생성]
        S4[결정 근거 설명]
    end

    H1 --> S1
    H2 --> S1
    S1 --> S2
    S2 --> S3
    S3 --> S4
    S4 --> H3
    H3 --> H4

    style Subagent fill:#e1f5ff,stroke:#0288d1
```
